隐私说明

最后更新：2026 年 11 月 4 日

公开测试版草案

当前由 Setpiece 项目团队维护。正式收费版本上线前，本页会补充实际运营主体的法定名称、注册地址、联系邮箱和适用法律。当前版本没有 Setpiece 账号系统、云端项目同步、应用内遥测或广告 SDK。

1. 概要

Setpiece 是一个本地优先的桌面应用。默认情况下，你的项目文件、素材、对话记录、设置和 API 密钥保存在你自己的电脑上。只有在你主动配置第三方服务、使用联网功能或访问下载页时，数据才可能离开你的电脑。

2. 保存在本地的数据

Setpiece 可能在本机保存：

  • 项目文件、生成的网页、图片、视频、音频和导出文件；
  • 项目版本历史、自动版本、缩略图和缓存；
  • 设置、主题、语言、窗口布局和快捷键偏好；
  • 本机 AI 助理的会话记录和日志；
  • 你为第三方服务填写的 API 密钥、地址、模型名称和其他服务配置。

这些数据的位置取决于你的操作系统、项目和设置。你可以通过文件管理器查看、备份或删除。删除应用不一定会删除项目文件；卸载前请自行确认项目库位置。

API 密钥保存在本机配置中，不会由 Setpiece 上传到我们的服务器。请使用操作系统账户权限、磁盘加密和访问控制保护你的电脑。任何软件都无法保证绝对安全。

3. 联网时会发送什么

更新与下载

应用可能向 set.tryworld.com.cn 和 GitHub Releases 请求版本信息、更新元数据和安装包，并从 npm、ffmpeg 或浏览器组件的发布源下载运行依赖。这些请求通常包含 IP 地址、User-Agent、请求时间和所请求的文件路径，由相应托管服务按其日志和隐私政策处理。

你配置的第三方服务

当你连接 AI、语音、图像、视频、音乐、字幕或其他媒体服务时，Setpiece 会把你选择发送的内容发送给该服务。内容可能包括提示词、项目文案、图片、音频、视频、素材路径和生成参数。第三方服务如何保存、使用和跨境传输这些数据，由该服务的条款和隐私政策决定。

如果你使用 Codex、Claude Code、Cursor 或其他 AI 助理命令行工具，这些工具可能把会话内容发送给各自的提供方。请在使用前检查该工具的登录方式、数据设置和隐私政策。

下载页与支持沟通

访问 set.tryworld.com.cn 时，托管服务商可能为安全、防滥用、性能和基础运营处理访问日志。你通过联系入口主动发送的信息会用于回复你的问题，并按处理该问题所需的时间保存。

4. 我们不做什么

当前版本中，我们不会：

  • 出售你的个人信息；
  • 使用你的项目内容建立广告画像；
  • 在应用内集成广告 SDK；
  • 把 API 密钥上传到 Setpiece 的自有服务器；
  • 声称提供端到端加密的云同步服务。

如果未来增加云同步、账号、遥测或付费服务，我们会在启用前更新本说明，并在适用情况下提供单独的同意或选择。

5. 保存期限与你的选择

本地数据由你控制，保存多久取决于你何时删除文件、清理缓存或卸载应用。第三方服务保存数据的时间由其政策决定，我们无法代为删除。

你可以通过以下方式行使与本地数据有关的权利：

  • 在项目库或文件管理器中查看、复制、导出和删除项目与素材；
  • 在设置中断开第三方服务并删除本机保存的密钥；
  • 删除本机应用数据目录和缓存；
  • 通过联系入口询问本说明或请求协助。

如果你所在地的法律赋予你访问、更正、删除、限制处理、反对处理或数据可携带的权利，请通过联系入口提出。我们需要确认请求与你的数据相关后才能处理。

6. 儿童

Setpiece 不是面向十四岁以下儿童设计的产品。我们不会有意收集儿童的个人信息。如果你认为儿童向我们提供了个人信息，请联系我们。

7. 安全

我们采取合理措施保护官方下载渠道和更新元数据，但互联网传输、第三方服务和你本机的安全不由我们完全控制。请只从官方地址下载 Setpiece，核对发布页提供的校验值，并及时安装操作系统和浏览器安全更新。

8. 说明变更

当功能、数据处理方式或运营主体发生变化时，我们会更新本页并修改“最后更新”日期。重大变化会在下载页或应用内以适当方式提示。

9. 联系

隐私问题请通过 TryWorld 联系入口 联系我们。许可和商业问题请阅读 最终用户许可协议。
