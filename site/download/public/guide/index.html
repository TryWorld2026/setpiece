开始使用造境

适用于 Desktop Preview 0.3.2 · Preview.4

1. 选择并安装

在官网下载区选择与电脑对应的版本：Apple Silicon、Intel Mac 或 Windows x64。 macOS 使用 DMG 打开后将 Setpiece.app 拖入「应用程序」；Windows 运行 EXE 安装程序。ZIP 是 macOS 的备用便携格式。

当前为未签名公开测试版。macOS 首次打开若被系统阻止，可在访达中右键应用并选择「打开」；也可执行 xattr -cr /Applications/Setpiece.app。Windows SmartScreen 可能提示「未知发布者」，确认文件来自本官网后再选择继续。

2. 从项目库开始

首次启动会进入项目库。可以新建作品、打开文件夹中的项目，或从示例开始。顶部标签页允许多个作品同时打开；项目库会保留在后方，不中断当前编辑。

编辑器从左到右是素材、画面、检查器和 AI 助理，下方是时间线。可在画面中直接选择元素，也可在时间线上移动、裁剪、分割或吸附片段，所有修改都能撤销。

3. 连接智能体与服务

AI 助理可以使用本机已安装的智能体命令行工具。媒体服务、模型与密钥在「设置」中配置，默认保存在本机。不连接任何服务也能打开项目、编辑时间线、播放和导出本地已有素材。

4. 导出作品

使用右上角「导出」生成 MP4、透明视频、图片、音频或剪辑工程文件。导出前请确认时间线长度、帧率、音频电平与字幕内容。处理大文件时，请保留足够的磁盘空间。

5. 命令行启动

需要 Node.js 22.18 或更新版本。npm 包为 @tryworld/setpiece，命令为 setpiece：

npx -y @tryworld/setpiece@latest open

这条命令启动本地 Studio，并在默认浏览器中打开项目库。项目与导出文件仍保存在你自己的电脑上。

6. 校验安装包

查看 SHA256 校验值。下载完成后，可在 macOS 终端运行 shasum -a 256 文件名，或在 Windows PowerShell 运行 Get-FileHash 文件名 -Algorithm SHA256，与官网列出的值核对。

7. 获取帮助

使用中遇到问题，请通过支持入口联系。可在应用「设置 → 开发者」中复制诊断报告；发送前请检查报告内容，不要包含密钥或私人素材。
