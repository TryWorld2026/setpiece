反馈前可以准备什么

  • 造境版本与安装包平台，可在应用「设置 → 关于」查看；
  • macOS 或 Windows 版本，以及 Apple Silicon、Intel 或 x64 架构；
  • 问题发生前的操作步骤，最好能稳定复现；
  • 应用「设置 → 开发者」中的诊断报告，发送前请先阅读内容；
  • 如涉及导出，请说明格式、分辨率、帧率和是否有外部素材。

常见问题

macOS 提示应用已损坏或无法打开

这是未签名测试版的常见系统提示。右键应用选择「打开」，或执行 xattr -cr /Applications/Setpiece.app。只运行从本官网下载并核对过校验值的安装包。

Windows 提示未知发布者

当前 EXE 未做代码签名。确认文件来自 setpiece.tryworld.com.cn 且 SHA256 与官网一致后，再决定是否继续。

AI 助理没有响应

检查本机智能体工具是否已安装并登录，在「设置 → 智能体」确认连接状态，再查看所选模型与第三方服务密钥是否有效。
